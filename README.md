**AI-Assisted Interface Erosion Detection**

An AI-assisted software analysis tool designed to detect potential interface erosion in object-oriented software projects.

- Evaluates object-oriented metrics such as **WMC, CBO, LCOM, RFC, and DIT**

### 🗺️ 2 · VYBE (EventTrail)
**Campus Event Discovery & Smart Navigation**

A campus event discovery and navigation application designed to help students find events and navigate between different campus locations.

<img src="https://img.shields.io/badge/React.js-1a0933?style=flat-square&labelColor=1a0933&color=e879f9" />
<img src="https://img.shields.io/badge/FastAPI-1a0933?style=flat-square&labelColor=1a0933&color=bef264" />
<img src="https://img.shields.io/badge/Python-1a0933?style=flat-square&labelColor=1a0933&color=bef264" />
<img src="https://img.shields.io/badge/NetworkX-1a0933?style=flat-square&labelColor=1a0933&color=fbbf24" />

- Discover and explore campus events
- Finds optimal routes between campus locations using **Dijkstra's algorithm**
- Graph-based campus navigation system with **25 nodes**
- Supports accessible and rain-sheltered route considerations
- Event clash, capacity, and scheduling validation
- QR-based event check-in

> 💡 **What I learned:** Graph algorithms, shortest-path optimization, API development, frontend-backend integration, and application logic.

🔗 **Repository:** [VYBE – EventTrail](YOUR_REPOSITORY_LINK)
